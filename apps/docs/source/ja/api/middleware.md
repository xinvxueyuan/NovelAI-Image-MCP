# `middleware`

`ToolCallLoggingMiddleware` — すべてのツール呼び出しを所要時間つきでログに記録し、モデルルーティングが有効な
間はルートごとの監査レコードを追記し、実験的ツールサーフェスをゲートします。結果を改変することはなく、
例外を握りつぶすこともありません。
