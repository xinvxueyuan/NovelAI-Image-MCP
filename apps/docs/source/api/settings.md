# `novelai_image_mcp.settings`

`pydantic-settings` models for environment-driven configuration. Two
models: `NovelAISettings` (credentials + generation defaults, `NOVELAI_*`
env vars) and `MCPServerSettings` (transport selection, `MCP_*` env vars).
